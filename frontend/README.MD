# 🌿 Plant Store Frontend

This is the frontend application for the **Plant Store Ecommerce Platform**, built using **Next.js** for better SEO, performance, and scalability.

---

## 🚀 Tech Stack

- Next.js
- React.js
- Tailwind CSS
- Axios
- Redux Toolkit / Context API
- React Icons
- Swiper.js
- JWT Authentication

---

## 🌱 Features

### User Features

- Home page
- Product listing
- Product detail page
- Category filtering
- Search plants
- Add to cart
- Buy now
- Wishlist
- Checkout
- User authentication
- Order tracking
- Responsive design
- SEO optimized pages

## ⚙️ Installation

### Install Dependencies

```bash
npm install
```

---

### Run Development Server

```bash
npm run dev
```

Application runs on:

```txt
http://localhost:3000
```

---

## 🔐 Environment Variables

Create `.env.local`

```env
NEXT_PUBLIC_API_URL=http://localhost:5000/api
NEXT_PUBLIC_CLOUDINARY_CLOUD_NAME=
NEXT_PUBLIC_RAZORPAY_KEY=
```

---

## 🏗 Build Project

```bash
npm run build
```

---

## 🚀 Production Start

```bash
npm start
```
