# 🌿 Plant Store Frontend

This is the frontend application for the **Plant Store Ecommerce Platform**, built using **Next.js** for better SEO, performance, and scalability.

---

## 🚀 Tech Stack

- Next.js
- React.js
- Tailwind CSS
- Axios
- Redux Toolkit / Context API
- React Icons
- Swiper.js
- JWT Authentication

---

## 🌱 Features

### User Features

- Home page
- Product listing
- Product detail page
- Category filtering
- Search plants
- Add to cart
- Buy now
- Wishlist
- Checkout
- User authentication
- Order tracking
- Responsive design
- SEO optimized pages
